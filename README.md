# 🌐 TNPHDSR - Frontend

A fast and responsive web interface for **TNPHDSR**, built using **React.js**, **Vite**, **Bootstrap**, and **Material-UI (MUI)**.

---

## 📁 Project Overview

This is a frontend-only application developed using:

- ⚡️ [Vite](https://vitejs.dev/) — blazing-fast build tool
- ⚛️ [React.js](https://reactjs.org/) — UI library
- 🎨 [Bootstrap](https://getbootstrap.com/) — responsive layout and components
- 🧩 [MUI](https://mui.com/) — Material Design components for React

---

## 🛠️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/AzhagammalRam/TNPHDSR.git
cd TNPHDSR



**Install dependencies**
npm install

**Development Server**
To start the development server: npm run dev

This will run the project at: http://localhost:5173/

**Build for Production**

npm run build
